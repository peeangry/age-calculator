# ชุดทดสอบ

```bash
# ทดสอบหลัก (ต้องมี playwright + chromium)
node tests/age-calc.test.mjs

# แสดงรายการที่ผ่านทั้งหมด
AGE_TEST_VERBOSE=1 node tests/age-calc.test.mjs

# ตรวจซ้ำกับ python-dateutil (implementation อิสระคนละภาษา)
AGE_TEST_DUMP=/tmp/ageof.tsv node tests/age-calc.test.mjs
python3 tests/crosscheck_dateutil.py /tmp/ageof.tsv
```

ชุดทดสอบเปิดไฟล์ `index.html` ในเบราว์เซอร์จริงและเรียกฟังก์ชันชุดเดียวกับที่หน้าเว็บ
ใช้ (`window.AgeCalc`) จึงไม่มีการคัดลอกตรรกะมาทดสอบซ้ำ ทุกชุดถูกรันซ้ำใน 8 เขตเวลา
รวมเขตที่มี DST, เขตที่ DST เริ่มตอนเที่ยงคืน (`America/Santiago`), DST ครึ่งชั่วโมง
(`Australia/Lord_Howe`), UTC+14 (`Pacific/Kiritimati`) และเขตที่เคยข้ามทั้งวัน
(`Pacific/Apia`, 30 ธ.ค. 2011)

## นิยามที่ใช้ (สำคัญเมื่อนำผลไปใช้งานจริง)

| หัวข้อ | นิยามที่หน้านี้ใช้ |
|---|---|
| อายุ ปี/เดือน/วัน | นับจำนวน "เดือนเต็ม" ที่บวกจากวันเกิดได้โดยไม่เกินวันปัจจุบัน แล้วส่วนที่เหลือเป็นวัน ตรงกับ `dateutil.relativedelta` ทุกเคสที่ทดสอบ (200,000 คู่) |
| วันเกิดเป็นวันท้ายเดือน | บวกเดือนแบบหนีบวันที่ให้อยู่ในเดือน เช่น 31 ม.ค. + 1 เดือน = 28/29 ก.พ. (ดังนั้น 31 ม.ค. → 28 ก.พ. ปีปกติ = "1 เดือน 0 วัน") |
| เกิด 29 ก.พ. | ปีที่ไม่ใช่ปีอธิกสุรทิน ถือว่าครบรอบวันที่ **28 ก.พ.** ซึ่งเป็นวันเดียวกับที่ตัวเลขอายุเพิ่มขึ้น (บางแห่งนับ 1 มี.ค. แทน) |
| การนับวัน | คำนวณบนปฏิทิน UTC ล้วน แล้วรับ "วันนี้" มาจากปฏิทินท้องถิ่นของเครื่อง — DST หรือวันที่ถูกข้ามทั้งวันในบางเขตเวลาจึงไม่มีผลต่อผลลัพธ์ |
| ชั่วโมงรวม | = จำนวนวันเต็ม × 24 (นับจากเที่ยงคืนของวันเกิด ไม่ใช่เวลาที่เกิดจริง) |
| ปีนักษัตร | นับตามปีปฏิทิน (1 ม.ค.–31 ธ.ค.) หน้าเว็บจะขึ้นหมายเหตุให้เองเมื่อวันเกิดอยู่ก่อนสงกรานต์ ซึ่งธรรมเนียมไทย/ตรุษจีนจะยังเป็นนักษัตรปีก่อน |
| ราศี | สากลใช้ช่วงวัน tropical มาตรฐาน ส่วนราศีไทยใช้วันเปลี่ยนราศีโดยประมาณ ซึ่งขยับได้ ±1 วันในแต่ละปี |
| อายุเกิน 150 ปี | ยังแสดงผล แต่ขึ้นคำเตือนว่าน่าจะเลือกปุ่ม พ.ศ./ค.ศ. ไม่ตรงกับปีที่กรอก |

## สิ่งที่ทดสอบ

1. `ageOf` — exhaustive ทุกคู่วัน (เกิด 2000–2003 × วันปัจจุบัน 2024–2027 = 2.1 ล้านคู่)
   ตรวจว่าประกอบกลับได้ตรง, นับเดือนได้สุด, ค่าอยู่ในช่วง และอายุไม่ลดลงเมื่อเวลาเดินหน้า
   บวกการสุ่มอีก 300,000 คู่ในช่วงปี 1900–2100
2. `dayDiff`, `daysInMonth` (ปี 1600–2400), `addMonths` (ทุกวัน × −36..36 เดือน),
   `makeDate` (ปี ค.ศ. 1–99 ต้องไม่ถูกเหมาเป็น 19xx)
3. `parseBirth` — exhaustive ทุก (วัน, เดือน) ของปีอธิกสุรทิน/ปีปกติ + อินพุตผิดรูปแบบ
   (ว่าง, 0, ติดลบ, 32, ตัวอักษร, ปีนอกช่วง, วันในอนาคต, ทศนิยม, ช่องว่างหัวท้าย)
4. วันเกิดครั้งถัดไป — exhaustive ทุกวันเกิด × ทุกวันในปี 2026–2027 ตรวจว่าไม่ข้าม
   วันเกิดที่ใกล้กว่า, จำนวนวันคงเหลือถูกต้อง, อายุที่จะครบถูกต้อง และตัวนับถอยหลัง
   เป็นศูนย์ในวันเดียวกับที่ตัวเลขอายุเพิ่มขึ้นพอดี
5. วันในสัปดาห์ — เทียบสูตร Zeller ที่เขียนแยกอิสระ ตลอดปี 1800–2200 + วันอ้างอิงจริง
6. ปีนักษัตร — ปีอ้างอิงที่ทราบคำตอบ + คาบ 12 ปี + ครบ 12 นักษัตรไม่ซ้ำ
7. ราศีทั้งสองระบบ — exhaustive ทุกวันในปี เทียบตารางช่วงวันที่เขียนแยกอิสระ
8. DOM — ผลที่แสดงจริง, ข้อความ error ทุกแบบ, ปุ่ม พ.ศ./ค.ศ., ปุ่ม Enter,
   คำเตือนอายุเกิน, การจำค่าใน localStorage (รวมกรณีข้อมูลเสียหาย) และต้องไม่มี console error
