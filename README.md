# คำนวณอายุ · ราศี · ปีนักษัตร

เว็บหน้าเดียวสำหรับคำนวณอายุจากวันเกิดเทียบกับวันปัจจุบัน

**เปิดใช้งาน: https://peeangry.github.io/age-calculator/**

กรอกวัน / เดือน / ปี (เลือกได้ว่าเป็น พ.ศ. หรือ ค.ศ.) แล้วได้

- อายุเป็น **ปี / เดือน / วัน** พร้อมยอดรวมเป็นวัน สัปดาห์ ชั่วโมง และเดือนเต็ม
- **วันเกิดครั้งถัดไป** เหลืออีกกี่วัน ตรงกับวันอะไร และจะครบกี่ปี
- **เกิดวันอะไรในสัปดาห์** พร้อมสีประจำวันเกิดแบบไทย
- **ปีนักษัตร** พร้อมหมายเหตุเมื่อวันเกิดอยู่ก่อนสงกรานต์ ซึ่งธรรมเนียมไทย/ตรุษจีนจะยังนับเป็นนักษัตรปีก่อน
- **ราศี** ทั้งระบบสากล (tropical) และโหราศาสตร์ไทย (นิรายนะ)

ทั้งหมดเป็นไฟล์ HTML ไฟล์เดียว ไม่มี dependency ไม่มี build step และคำนวณในเครื่องผู้ใช้ทั้งหมด
ค่าที่กรอกล่าสุดถูกเก็บไว้ใน localStorage ของเบราว์เซอร์เท่านั้น ไม่มีการส่งข้อมูลออกไปที่ใด

## นิยามที่ใช้

| หัวข้อ | นิยาม |
|---|---|
| อายุ ปี/เดือน/วัน | นับ "เดือนเต็ม" ที่บวกจากวันเกิดได้โดยไม่เกินวันปัจจุบัน แล้วส่วนที่เหลือเป็นวัน — ตรงกับ `dateutil.relativedelta` |
| วันเกิดเป็นวันท้ายเดือน | บวกเดือนแบบหนีบวันที่ให้อยู่ในเดือน เช่น 31 ม.ค. + 1 เดือน = 28/29 ก.พ. |
| เกิด 29 ก.พ. | ปีที่ไม่ใช่ปีอธิกสุรทิน ถือว่าครบรอบวันที่ 28 ก.พ. ซึ่งเป็นวันเดียวกับที่ตัวเลขอายุเพิ่มขึ้น |
| การนับวัน | คำนวณบนปฏิทิน UTC ล้วน ใช้เวลาท้องถิ่นแค่ตอนอ่าน "วันนี้" — DST หรือวันที่ถูกข้ามในบางเขตเวลาจึงไม่มีผล |
| ชั่วโมงรวม | จำนวนวันเต็ม × 24 (นับจากเที่ยงคืนของวันเกิด ไม่ใช่เวลาที่เกิดจริง) |
| ปีนักษัตร | นับตามปีปฏิทิน (1 ม.ค.–31 ธ.ค.) |
| ราศีไทย | วันเปลี่ยนราศีเป็นค่าประมาณ ขยับได้ ±1 วันในแต่ละปี |

เมื่ออายุที่คำนวณได้เกิน 150 ปี หน้าเว็บยังแสดงผลแต่จะขึ้นคำเตือน เพราะมักเกิดจากกดปุ่ม
พ.ศ./ค.ศ. ไม่ตรงกับปีที่กรอก

**ข้อจำกัด:** ไม่รับเวลาเกิด (นับจากเที่ยงคืนของวันเกิด) และ "วันนี้" มาจากนาฬิกาเครื่องผู้ใช้

## ทดสอบ

```bash
npm i -D playwright && npx playwright install chromium
node tests/age-calc.test.mjs
```

ชุดทดสอบเปิด `index.html` ในเบราว์เซอร์จริงและเรียกฟังก์ชันชุดเดียวกับที่หน้าเว็บใช้
(`window.AgeCalc`) จึงไม่มีการคัดลอกตรรกะมาทดสอบซ้ำ รันซ้ำทั้งชุดใน 8 เขตเวลา รวมเขตที่
DST เริ่มตอนเที่ยงคืน, DST ครึ่งชั่วโมง, UTC+14 และเขตที่เคยข้ามทั้งวัน

```
530 checks / 0 failures  (10,441,396 generated cases across 8 timezones)
```

ตรวจซ้ำกับ `python-dateutil` ซึ่งเป็น implementation อิสระคนละภาษาได้ด้วย

```bash
AGE_TEST_DUMP=/tmp/ageof.tsv node tests/age-calc.test.mjs
python3 tests/crosscheck_dateutil.py /tmp/ageof.tsv    # 200,000 คู่ ไม่ตรงกัน 0
```

รายละเอียดว่าทดสอบอะไรบ้างอยู่ใน [`tests/README.md`](tests/README.md)
